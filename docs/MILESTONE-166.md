# Milestone 166 — Preflight binds local script to declared work

The real Linux producer preflight now replays the manifest before launching runtime inspection or optional network probing. A changed URL, run ID, JVM count, target rate, workload volume or start instant is rejected instead of producing misleading readiness evidence.

Scope: offline software-level consistency on an operator-controlled trusted plan, not authenticated physical hosts, not a production benchmark, and not proof of universal exactly-once effects.
