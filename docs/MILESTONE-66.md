# Milestone 66 — Three real terminal convergence observations with descriptive dispersion

The existing three isolated real Spring trials now require a verified terminal observer result per repetition, then compute median and median absolute deviation for the interval from **first observed admission** to **first observation of all DONE**. The CI evidence gate requires nonnegative numeric values and a completed observation in the short, two-minute soak and repeated-trial runs.

The data are deliberately labeled descriptive. Three observations on one hosted runner, with active SQL polling, do not establish a stable population percentile, a provider completion-time distribution, hardware isolation, causality or an endurance certificate. The sampling resolution is 0.5s for these three short trials. Comparison against gateway HTTP response QPS remains separate.
